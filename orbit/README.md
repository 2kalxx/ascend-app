# Orbit Crush (Android)

Idle arcade game: balls bounce inside a glowing ring and smash pixel blocks for coins; upgrades (Size, Income, Speed, Balls, Power), stages with new patterns, tap boost, offline earnings.
UI: `web/index.html` (bump `ORBIT_WEB_VERSION` and `"web"` in `version.json` → auto-update on next app start).
Native wrapper sources in `android/`, signed with the same key as Ascend.

Install link: https://raw.githubusercontent.com/2kalxx/ascend-app/main/orbit/apk/OrbitCrush.apk
